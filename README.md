# Screenshooter

Разбор скриншотов и записей экрана на macOS по папкам — сразу после снимка, одной клавишей.

Сделали скриншот (`Cmd+Shift+3/4/5`) или запись экрана — открывается окно с крупным предпросмотром. Жмёте `1`, `2` или `3` — файл уезжает в нужную папку и сжимается в фоне. Серия снимков разбирается подряд в том же окне с прогрессом `3 / 12`.

## Возможности

- **Одно окно на всю очередь** — картинка и счётчик в заголовке просто меняются, без всплывающих диалогов.
- **Категории и подпапки** — например «Вёрстка → Проект», папки можно создавать прямо из окна.
- **Liquid Glass** (macOS 26) — стеклянные кнопки, перетекающие между уровнями, размытый снимок на фоне.
- **Лупа** при наведении на предпросмотр, включается и выключается правой кнопкой мыши.
- **Перетаскивание** предпросмотра в Telegram, Slack и другие приложения — уходит копия файла.
- **Не попадает в скриншоты и записи экрана**, даже если снимать весь экран.
- **Сжатие в фоне**: PNG — без потерь (`oxipng`), видео — H.265 с визуально неотличимым качеством (`ffmpeg`). Дата создания и теги Finder сохраняются, оригинал видео уходит в Корзину.
- **Трей** — окно можно спрятать, в строке меню остаётся значок со счётчиком очереди.
- **На всю ширину экрана** — зелёная кнопка или `F`.
- Окно подстраивается под пропорции снимка, без пустых полей.

## Клавиши

| Клавиша | Действие |
|---|---|
| `1` `2` `3` | Категория. Без подпапок — файл переносится сразу, с подпапками — открывается второй уровень |
| `1` (на втором уровне) | В саму категорию |
| `2`…`9` (на втором уровне) | В подпапку |
| `N` | Новая подпапка (название → `Enter`) |
| `Esc` | Назад |
| `Delete` | В Корзину |
| `F` | На всю ширину экрана и обратно |
| Правая кнопка мыши | Лупа вкл/выкл |
| Жёлтая / красная кнопка окна | Спрятать в трей |

## Установка

Нужны macOS 26 (Tahoe), Apple Silicon и [Homebrew](https://brew.sh) — через него ставятся `ffmpeg` и `oxipng`.

**Из исходников** (нужны Xcode Command Line Tools: `xcode-select --install`):

```bash
git clone https://github.com/lozhka13/Screenshooter.git
cd Screenshooter
./install.sh
```

**Из релиза**: скачайте архив со [страницы релизов](https://github.com/lozhka13/Screenshooter/releases), распакуйте и запустите `./install.sh` — будет установлен готовый бинарник.

Установщик:

- кладёт приложение и скрипт сжатия в `~/bin`;
- переключает сохранение скриншотов в `~/Screenshots/Inbox`;
- регистрирует автозапуск (`~/Library/LaunchAgents/com.screenshooter.sorter.plist`) — приложение стартует само, когда в Inbox появляется файл, и закрывается, когда всё разобрано.

Рекомендуется отключить плавающую миниатюру: `Cmd+Shift+5` → «Параметры» → снять «Показывать плавающую миниатюру». Иначе снимок попадает в Inbox только после того, как миниатюра исчезнет, а если перетащить миниатюру в чат, файл не сохранится вовсе.

## Настройка категорий

Категории задаются в начале `Sources/main.swift`:

```swift
let categories = [
  Category(label: "Wingform", folder: "Wingform", hasSubfolders: false),
  Category(label: "Вёрстка", folder: "Verstka", hasSubfolders: true),
  Category(label: "Личное", folder: "Личное", hasSubfolders: true),
]
```

`label` — подпись на кнопке, `folder` — папка в `~/Screenshots`, `hasSubfolders` — показывать ли второй уровень. Шорткат — порядковый номер. После правки снова запустите `./install.sh`.

Подпапки берутся с диска: всё, что лежит в `~/Screenshots/<папка>/`, появляется на втором уровне по алфавиту.

## Как это устроено

- `Sources/main.swift` — приложение на SwiftUI/AppKit. Следит за Inbox, ставит в очередь файлы, которые перестали расти, показывает окно и переносит файлы.
- `scripts/screenshot-compress.sh` — сжатие одного файла на месте. Запускается приложением после переноса, по одному файлу и с низким приоритетом.
- launchd `WatchPaths` запускает приложение при изменении Inbox.

Лог ошибок — `~/Screenshots/.sorter.log`.

## Ограничения

- Окно скрыто от системного захвата экрана (`screencapture`, `Cmd+Shift+3/4/5`). Программы со своим захватом (Zoom, Google Meet, OBS) на новых macOS иногда всё равно его показывают.
- Сжатие видео — не lossless в строгом смысле: H.265 CRF 22, SSIM ≈ 0,998. На глаз отличий нет, размер записи экрана уменьшается в 5–7 раз.
- Встроенная запись экрана macOS пишет только микрофон, без звука системы.

## Удаление

```bash
./uninstall.sh
```

Удаляет приложение и автозапуск и возвращает скриншоты на Рабочий стол. Папка `~/Screenshots` с разобранными файлами остаётся.
